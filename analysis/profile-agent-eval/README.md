# Проверка агента подготовки инструкций

Fixtures — синтетические сокращённые карточки, не выгрузки приватной БДХК. Имена двух игр служат контрольными метками; приведённые факты не являются полной карточкой игры.

Локальные тесты проверяют все 14 справок, точные коды, редкую локаль, идентичные имена, разные черновики, атомарное сохранение и сохранение ручных правок. Заглушки подтверждают контракты и поведение очереди, но не качество текста реальной модели.

Перед включением GPT-6 Luna: подключить закрытый ключ OpenRouter; получить разрешение на максимум четыре оплачиваемых запроса без автоматических повторов. Подать четыре fixtures с целями zh_Hans, zh_Hant, ja, pt_BR, es_MX. Для конфликтной карточки нужны явное предупреждение и ручная проверка, а не молчаливый выбор противоречивого правила.

Оценивать каждый результат по категориям: точность фактов, терминология, стиль, локальные соглашения, сохранение тегов/переменных/чисел/$, отсутствие новых фактов, краткость. Требуются 100% соответствие схеме и кодам, ноль критических ошибок и независимая ручная оценка содержания. Сохранить только обезличенные результаты, фактические model/usage и версию навыков; ключ и reasoning не сохранять.
