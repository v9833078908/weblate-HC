Метки исходника

Достаточно одной из выбранных меток: метки складываются по «или», а не по «и». Пустой набор меток означает все строки выбранных компонентов, и тогда preview попросит отдельное подтверждение области.

Область применения: компоненты dialogs, ui; метки ui, quest — сработает, если у строки есть любая из этих меток.

Правило отвечает за будущие строки и запуски. Уже переведённое оно не трогает: ни один текущий перевод при сохранении правила не меняется.
Это правило пересекается с активным правилом ui dialogs на тех же строках. Победителя по порядку создания нет: измените область одного из правил.
