HCGameLoc
=========

Fork of `Weblate <https://weblate.org/>`_, a web-based continuous
localization system, adapted for localizing the game
"Hero Craft Space Arena". Maintained by v9833078908.

Documentation
-------------

See the ``docs`` directory of the source code.
Upstream documentation is available at https://docs.weblate.org/.

Development
-----------

The development instance runs in Docker, see ``dev-docker/README.rst``
and ``./rundev.sh`` in the repository root.
