# План: Space Arena LocKit — чистый вид для продюсера (только SQUADRONS)

> **Статус:** выполнено на проде 2026-08-19 (`l10n.herocraft.com`, проект
> `space-arena`, компонент `lockit`, английский источник). Обе фазы отработаны и
> проверены — см. «Результат выполнения» внизу.

## Цель

Подготовить компонент так, чтобы продюсер/геймдизайнер, зайдя в `lockit`, видел
как непереведённые **только строки нового режима SQUADRONS** (то, что ему нужно
перевести следующей задачей), а не 4 831 строку. Всё остальное непереведённое —
намеренно английский контент (названия кораблей, описания, страны, событийные
письма и т.п., где игра показывает английский фолбэк) — убирается из очереди
перевода пометкой `read-only`. Правка обратима, файлы игры не меняются.

## Замер (прод, 2026-08-19)

- `lockit`: источник `en`, 15 языков, 4 861 ключ, 72 915 юнитов. Уже `read-only`
  на 195 ключах (2 925 юнитов, источник-уровень).
- Непереведённых (пустой таргет, не `read-only`) — **4 831** по 14 целевым
  языкам (`en` — источник, 0). По языкам: de 340, es 349, fa 381, fr 349, hi 398,
  id 400, ja 350, ko 347, pt_BR 362, th 400, tr 379, vi 400, zh_Hans 351, ru 25.
- **SQUADRONS** (ключи, у которых в контексте есть `SQUADRON`): 52 ключа.
  Полностью переведены в `ru` и в `en` (источник). В каждом из 13 остальных
  языков — **38 пусто / 14 заполнено**. Итого пустых SQUADRONS: **494**
  (38 × 13).
- **Не-SQUADRONS пустых: 4 337** (4 831 − 494) — это и есть кандидаты на
  `read-only`.
- Внутри 4 337: 24 «универсальных» ключа пусты во всех 14 языках (описания
  кораблей/боссов `*_DESC%`, 336 юнитов) — это п.2; остальные 4 001 — частичные
  (переведены в части языков, пусты в других).

## Механика (проверено по коду)

- `read-only` во флагах юнита → `Unit.get_unit_state` возвращает `STATE_READONLY`
  (`weblate/trans/models/unit.py:1152`). Флаги сливаются в порядке
  `translation → file → source_unit.extra_flags → self.extra_flags`
  (`unit.py:2478`): **свой** `extra_flags` — это пер-юнитный оверрайд, поэтому
  флаг на одном таргет-юните лочит только его, не трогая другие языки того же
  ключа. Пустые ячейки частичных ключей парковать безопасно — существующие
  переводы остаются переводами.
- Ставим **пер-юнитно на пустые таргет-юниты** (не на источник), поэтому чужие
  переводы и сам английский источник не трогаются.
- Применение массово: `bulk_update(["extra_flags","original_state","state"])`,
  минуя `update_extra_flags` (тот делает `generate_change` на юнит — 4 337 строк
  истории и таймаут; урок из памяти). Для каждого: `original_state = state (0)`,
  `state = STATE_READONLY`.
- Стабильно при пересчёте: `update_state()` (`unit.py:1563`) видит `read-only` во
  флагах и держит `STATE_READONLY`; снятие флага возвращает `original_state`.
- Кэш статистики после `bulk_update` инвалидируем вручную
  (`translation.invalidate_cache()` по каждому языку) — сигналы `bulk_update` не
  шлёт.

## Фаза A (п.2) — 24 универсальных ключа

Пометить `read-only` пустые таргет-юниты 24 ключей `*_DESC%` (336 юнитов, 14
языков). Ожидаемо: непереведённых 4 831 → **4 495**.

## Фаза B (п.3) — остальные не-SQUADRONS пустые

Пометить `read-only` все оставшиеся пустые таргет-юниты, чей контекст **не** в
множестве SQUADRONS (context `SQUADRON`). Ожидаемо: непереведённых → **494**,
т.е. только SQUADRONS: по 38 в 13 языках, `ru` 0, `en` 0.

Итог для продюсера: открывая любой не-`ru` язык, он видит ~38 непереведённых
строк — все из режима SQUADRONS.

## Проверка

- После каждой фазы: пересчёт непереведённых по языкам, инвалидация кэша.
- Финал: непереведённых = 494, все контексты — из множества SQUADRONS; переводы
  (`translated`) остальных языков не изменились (парковали только пустые);
  15 JSON-файлов остаются побайтово идентичными (флаги/состояние — только в БД).

## Откат

```python
# вернуть распаркованное (только наши пер-юнитные read-only на пустых таргетах):
from weblate.checks.flags import Flags
qs = Unit.objects.filter(translation__component=c, target="").exclude(
    translation__language=c.source_language)
buf = []
for u in qs:
    fl = Flags(u.extra_flags)
    if "read-only" in fl:            # 195 старых — источник-уровень, тут пусто
        fl.remove("read-only"); u.extra_flags = fl.format()
        u.state = u.original_state    # 0 (пусто)
        buf.append(u)
Unit.objects.bulk_update(buf, ["extra_flags","state"], batch_size=500)
```

Существующие 195 `read-only` заданы на уровне источника (у их таргет-юнитов
собственный `extra_flags` пуст), поэтому наш откат их не трогает.

## Вне объёма

- Проверки (терминальная пунктуация ~962, `multiple_failures`) — идут по
  **заполненным** строкам, парковка пустых их не меняет; отдельный заход, как и
  договаривались.
- Ранги/плейсхолдеры внутри SQUADRONS (`ACE-1`, `{0}/{1}`, `SLOT #{0}`) остаются
  видимыми продюсеру — решение переводить их или нет за ним.
- Правки файлов игры, деплой, изменения кода — не входят.

## Результат выполнения (2026-08-19)

Через `weblate shell` на проде, актор — суперюзер. `bulk_update` без
`generate_change` (истории не плодим), в транзакции, с инвалидацией кэша.

- **Фаза A:** помечено `read-only` 336 пустых таргет-юнитов 24 ключей `*_DESC%`;
  непереведённых 4 831 → **4 495**. Базовый замер пер-юнитных `read-only`
  до правки — 0 (наши флаги отличимы от старых 195 источник-уровня).
- **Фаза B:** помечено `read-only` **4 001** пустой не-SQUADRONS юнит;
  непереведённых 4 495 → **494**. Инвариант: среди оставшихся непереведённых
  не-SQUADRONS = **0** — видно только SQUADRONS.
- Всего запарковано 336 + 4 001 = **4 337** (= все не-SQUADRONS пустые).
  `read-only` по компоненту 2 925 → **7 262**.
- **Для продюсера:** непереведённых **494**, все из режима SQUADRONS: по **38**
  в каждом из 13 языков, `ru` 0 (переведён полностью), `en` 0 (источник).
  SQUADRONS-переводы не тронуты: `ru` 52/52 заполнено, `de` 14 заполнено /
  38 видимо к переводу.
- **Контент перевода не изменён.** Статистика `translated` выросла (de 4521 →
  4823 и т.д.), потому что в Weblate `read-only` (`state 100 ≥ TRANSLATED`)
  считается «готовым»; это рост за счёт парковки пустых, а не новые переводы.
  Доказательство неизменности: все **15 JSON-файлов побайтово идентичны**
  архивному `lockit-ru` (`differing_files=[]`), `needs_commit=false`; реальные
  переводы по языку совпадают (de: 4823 − 497 `read-only` = 4326 = было
  4521 − 195). Проверки — **1 348**, без изменений (идут по заполненным строкам).
