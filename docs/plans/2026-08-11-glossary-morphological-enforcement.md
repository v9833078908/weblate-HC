# План: морфологическое сравнение для глоссарного гейта

Статус: **ожидает согласования**. Обоснование и все числа -
`docs/misc/2026-08-11-glossary-enforcement-analysis.md`.

Цель: сделать `GlossaryCheck` пригодным как автоматический гейт в LLM-first
пайплайне без человека, не раздувая глоссарии словоформами.

## Задача 1. Морфологическое сравнение в тесте вхождения

Файлы: `pyproject.toml`, `weblate/checks/glossary.py`, новый
`weblate/checks/morphology.py`, тесты в
`weblate/checks/tests/test_glossary_checks.py`.

- Объявить `snowballstemmer` в `[project] dependencies` (BSD-3-Clause, чистый
  Python, 762 КБ, без своих зависимостей).
- `weblate/checks/morphology.py`: карта код языка -> алгоритм Snowball и
  функция `contains_inflected(term, text, language)`, которая сравнивает
  последовательность основ как непрерывный отрезок. Индонезийский в карту **не
  входит** - Snowball срезает там префиксы и склеивает разные слова
  (152 ложных совпадения из 206, пункт 4 отчёта).
- В `GlossaryCheck.check_single` дополнить существующий тест: если дословное
  вхождение не найдено, принять морфологическое. Порядок сохраняет текущее
  поведение как быстрый путь.
- Сторону источника (матчер в `weblate/glossary/models.py`) **не трогать**:
  стемминг там даёт +34% вхождений, но 42% прироста падает на шумные термины
  (пункт 7 отчёта).
- Флаг `forbidden` оставить на дословном сравнении: расширять запрет
  морфологией - отдельное решение с обратной ценой ошибки.

Приёмка: новые тесты на замеренных случаях - `Корабль`/`корабля`,
`Двигатель`/`двигателя`, `Bauplan`/`Bauplänen`, `Galaktischer Träger`/`Galaktischen
Trägers`, `Modül`/`modülüne`; и обратный тест, что индонезийские
`Dukungan`/`pendukung` и `Batas terakhir`/`Perbatasan Terakhir` **не**
считаются совпадением. Существующие тесты `GlossaryCheckTest` зелёные.

## Задача 2. Замер до и после на трёх китах

Файлы: `docs/misc/glossary-blindspot-probe.py`, результат в
`docs/misc/2026-08-11-glossary-enforcement-analysis.md`.

Прогнать замер против новой функции вместо локальной копии правила и
подтвердить снятие 14-66% по языкам. Расхождение с уже записанными числами -
дефект реализации, а не новая норма.

Приёмка: числа в отчёте совпадают с прогоном через продуктовый код.

## Задача 3. Область применения термина пер-язык

Отдельная задача, требует решения по механизму - согласовать до реализации.
Варианты: флаг на юните глоссария против настройки компонента; чек enforce'ит
только термины, помеченные обязательными.

Основание: пересечение чистых терминов по всем языкам - 5 из 299, поэтому
единого списка не существует (пункт 6 отчёта).

## Задача 4. Перезамер по выходу пайплайна

Все числа стороны цели получены на легаси-переводах из китов. Нужен прогон чека
по строкам, которые произвёл пайплайн. **Требует чтения прода** - согласовать
отдельно, по правилу про деплой.
