HCGameLoc Documentation
=======================

Welcome to the documentation of HCGameLoc, a fork of `Weblate
<https://weblate.org>`_, the libre software web-based continuous localization
system, adapted for localizing the game "Hero Craft Space Arena".

First time here?
----------------
Read the :doc:`user/basic` to get an overview of what the system does.

Joining a translation project
------------------------------
If you would like to contribute to a project as a translator, read about :doc:`user/translating`.

Starting a translation project
-------------------------------
For self-hosting your own instance, read our :doc:`admin/install`.

FAQ
----
Check our :doc:`faq`.

Community
----------
Learn more about :ref:`contributing`.
