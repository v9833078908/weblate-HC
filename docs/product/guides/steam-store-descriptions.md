# Описания для Steam в Weblate

Инструкция для релиз-менеджера: как завести тексты страницы Steam в Weblate и
перевести их автоматическим переводом.

Steam отличается от Google Play и App Store: у Weblate **нет** формата и
интеграции под Steam. Формат «Файлы метаданных магазина приложений»
(`appstore`, `weblate/formats/txt.py:202`) заточен под Google Play и App Store —
имена полей и лимиты в нём зашиты (`txt.py:128-145`). Поэтому Steam заводится
обычным одноязычным компонентом на JSON, а выгрузка в Steamworks — отдельный
шаг, который Weblate не выполняет.

Для стандартного потока Google Play и App Store смотри инструкцию по метаданным
магазинов; здесь только Steam.

## 0. Что нужно иметь

- Доступ к проекту: команда проекта :guilabel:`Translate` **и**
  :guilabel:`Automatic translation`. Право автоперевода (`translation.auto`)
  не входит в роль `Translate` (`weblate/auth/data.py:183-191`), его даёт
  отдельная команда. Если языки добавляешь сама — ещё
  :guilabel:`Manage languages`.
- Настроенный движок автоматических предложений на проекте (OpenRouter или
  LiteLLM).
- Актуальные лимиты полей из Steamworks. Не угадывать: значения берутся из
  Steamworks и подставляются флагом `max-length`.

## 1. Подготовить файл

Папка `steam` → внутри один файл исходного языка `ru.json`. Ключ = поле
страницы Steam, значение = текст поля.

```json
{
  "short_description": "Пиратская морская баталия: собирай флот, штурмуй форты.",
  "about_the_game": "[b]Pirate Ships[/b]\n[list]\n[*]Более 100 парусников\n[/list]",
  "legal": "© HeroCraft. Все права защищены."
}
```

Набор ключей — по полям страницы в Steamworks; именовать латиницей, без
пробелов. Разметка Steam (`[b]`, `[list]`, `[*]`, `[url=]`, `[img]`) пишется
как есть, она часть текста.

Правый клик по папке `steam` → **Сжать**. Получится `steam.zip`.

## 2. Создать компонент

:guilabel:`Добавить` → :guilabel:`Добавить новый компонент перевода` → вкладка
:guilabel:`Отправить файлы перевода`.

| Поле | Значение |
| --- | --- |
| Архив | `steam.zip` |
| Название компонента | `Steam` |
| URL-плашка | `steam` |
| Исходный язык | Русский |

## 3. Выбор файлов

Отметить строку с форматом **JSON** (`json`) и маской файла `steam/*.json` →
:guilabel:`Продолжить`.

## 4. Второй экран — заполнить базовый файл

| Поле | Значение |
| --- | --- |
| Одноязычный базовый файл языка | `steam/ru.json` |

Само не подставится. Без него компонент прочитается как двуязычный.
:guilabel:`Сохранить`.

## 5. Включить проверку разметки Steam

:guilabel:`Настройки` → вкладка :guilabel:`Перевод` → поле
:guilabel:`Флаги перевода` → `bbcode-text` → :guilabel:`Сохранить`.

Проверка `bbcode` по умолчанию выключена и включается именно этим флагом
(`weblate/checks/markup.py:275-291`). После включения потерянный или
переименованный тег Steam становится красной проверкой.

Лимит длины — на конкретное поле, не на компонент: открыть строку исходного
языка → :guilabel:`Флаги перевода` → `max-length:300` (число — из Steamworks).

`GameMarkupCheck` форка здесь не участвует: он про Unity-теги, а не про BBCode.

## 6. Добавить языки

:guilabel:`Добавить` → :guilabel:`Добавить новый перевод` → отметить языки →
:guilabel:`Добавить`. Ключи из базового файла появляются в новом языке
автоматически, все пустые.

У Steam свои региональные варианты, брать их явно:

- Portuguese (Brazil) и Portuguese (Portugal) — это два разных языка Steam;
- Spanish (Spain) и Spanish (Latin America) — тоже два разных;
- Chinese (Simplified) и Chinese (Traditional) — тоже два разных;
- English у страницы Steam один — вариант со страной не нужен, в отличие от
  Google Play и App Store.

Имена файлов внутри Weblate (`steam/pt_BR.json`) — внутренние, Steam их не
видит, менять стиль кода языка не нужно.

## 7. Перевести

1. :guilabel:`Операции` → :guilabel:`Автоматический перевод` → **один язык за
   раз** → :guilabel:`Выполнить`.
2. :guilabel:`Проверки` → красное чинить руками. Для Steam обычно это `bbcode`
   (сломанная разметка) и `max-length` (перебор лимита поля).

## 8. Отдать тексты в Steam

:guilabel:`Файлы` → :guilabel:`Скачать перевод` даёт готовый JSON языка; либо
текст копируется из редактора строки.

Автоматической выгрузки в Steamworks нет: у Weblate нет Steam-интеграции и
экспорта под Steam. Способ переноса (ручная вставка в Steamworks или свой
скрипт) команда определяет отдельно; Weblate остаётся источником правды по
тексту и памятью переводов.
