# Удаление тестовых проектов визарда

**Дата:** 2026-10-02. **Статус:** выполнено по подтверждению владельца.

Из локального визарда удалены три карточки: «тест — c2714e46», Lord Ambermaze и Dead Shell. Вместе с ними удалены 6 заданий и связанные профили/экспорты — всего 12 записей `records`; три каталога результатов перенесены в архив. Временный черновик успел истечь до очистки и не требовал удаления.

Во внешнем Weblate удалены строго два проекта:

| Проект | Slug | ID | Проверка результата |
| --- | --- | --- | --- |
| тест | `test-5dacb142c2714e46-3cc5dcb7` | 20 | HTTP 404 |
| Lord Ambermaze | `wizard-58022f2c0c50452a-e23aa04f` | 21 | HTTP 404 |

Сохранённые ответы создания HTTP 201 подтверждали происхождение обоих проектов из визарда. После удаления остальные **13 проектов и 41 компонент** сохранили ID, slug и ссылки на репозитории. Существующий внешний Dead Shell (`dead-shell`, ID 11) возвращает HTTP 200 и не изменялся. Запланированный, но отклонённый внешний slug новой карточки Dead Shell не удалялся.

До удаления сохранены SQLite и файлы визарда, метаданные и архивы всех языков двух внешних проектов. Проверены целостность SQLite, контрольные суммы файлов и ZIP. Архив находится на сервере:

`/opt/bdhc/weblate-wizard/shared/backups/cleanup-20261002-approved`

`before.sqlite` и `local/wizard.sqlite` содержат прежние данные; `before-files`, `local/files-backup` и `local/removed` — файлы результатов; `external/<slug>/translations.zip` — внешние переводы. Manifest, контрольные суммы, перечни внешних проектов до/после и `external-removal.json` фиксируют точные объекты операции. Локальная SQLite не является полной резервной копией внешнего Weblate и сама по себе не восстанавливает удалённый внешний проект.

После очистки проверен реальный вход в визард по LAN. Страница проектов и API доступны с HTTP 200, список пуст; три удалённые карточки возвращают HTTP 404. Пользователь, 11 прежних сессий, heartbeat, настройки и токены сохранены. Проверочная сессия закрыта.

Readiness визарда и health-check основного API, интерфейса карточек и фасада БДХК вернули HTTP 200. PID API `1001139`, UI `1027425`, Telegram-бота `1052749`, фасада `1076287` не изменились. На короткое время останавливались только `wizard-api` и `wizard-worker`; обе службы и `wizard-backup.timer` активны.

Скрипт `scripts/cleanup_wizard_projects.py` действует по закрытому списку owner/slug, проверяет активные задания, lease, неподтверждённые операции, изменения снимка, общие экспорты/файлы и symlink. По умолчанию он только составляет отчёт. Проверки: **54 passed**, Ruff — без ошибок; независимая проверка скрипта проведена перед запуском. Исходники приложения на сервере не заменялись. Изменения сохранены в отдельном локальном репозитории; remote у него отсутствует.
