## Возврат и ограничения

Для dry-run проверки и полного возврата используется явная точка:

```bash
sudo bash /opt/bdhc/weblate-wizard/current/deploy/rollback.sh /opt/bdhc/weblate-wizard/shared/backups/preinstall-20261004T191049Z code --dry-run
sudo bash /opt/bdhc/weblate-wizard/current/deploy/rollback.sh /opt/bdhc/weblate-wizard/shared/backups/preinstall-20261004T191049Z full
```

Реальный откат — операция по отдельному решению, сейчас он не выполнялся. Полное восстановление сохраняет состояние после обновления, возвращает baseline и запускает API. Worker отключается и маскируется до сверки журнала. Изолированная репетиция фактического rollback-скрипта проведена до установки; real systemctl и внешние запросы в ней отсутствовали.

Внешняя запись остаётся выключенной. Подключённые существующие проекты и legacy-привязки защищены даже при последующем разрешении записи новым проектам. Новый платный тест и включение записи не выполнены; фактическое выполнение внешней Celery/LLM-задачи этим отчётом не подтверждается. Нагрузочная приёмка отложена по согласованному плану. Проверка скачивания и сохранения прежних языков выполнена локальными регрессиями; при отсутствии локальных проектов production-скачивание не заявляется проверенным.

Исходная ветка остаётся отдельной, remote у репозитория не настроен. Переданы исходный ZIP, полный Git bundle и отдельный комплект сопровождения с исправленным установщиком. Исходный ZIP `weblate-wizard-29771e247aca.zip` сохраняет прежнюю SHA256 `5d632ffac511bde59bcafd71c811a601306728363bdbaac9efff71d537bb9210`.

Все принятые при реализации решения и последствия перечислены в `docs/product/reports/2026-10-04-persistent-wizard-release.md`. Дополнительное решение при установке: поправить доступ только к созданному runtime и проверить запуск служебным пользователем; цена — новый regression fixture и отдельная версия установщика, без расширения прав доступа к секретам.
