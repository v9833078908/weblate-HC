# Автоматическое подтверждение сохранённого перевода

Дата: 2026-10-02. Установлен выпуск `release-eca64adcab63`, commit `eca64ad`, по адресу http://192.168.0.180:18511/console/.

В задании Lord Ambermaze внешний Weblate возвращал серверную ошибку после фактического сохранения переводов. Worker немедленно фиксировал состояние `unknown`, не выполняя доступную проверку результата. Пользователю требовалось вручную продолжать задание после каждого такого ответа.

Worker теперь перехватывает неизвестный результат MT, сохраняет намерение и проверяет переводы без повторного POST. Готовый результат продолжает задание автоматически. Для отложенного результата, временных сбоев чтения и HTTP 202 без адреса задачи предусмотрено ограниченное ожидание: чтение примерно каждые 30 секунд, до пяти минут. Сохранённый срок не сбрасывается при перезапуске. Если результат остаётся неполным, задание останавливается с неизвестным результатом и сохраняет защиту от повторного платного вызова.

Регрессионные проверки сначала воспроизвели старую остановку. После исправления проходят 26 тестов backend, Ruff и проверка diff. Проверены немедленный результат, отложенное появление, перезапуск, временные сетевые и серверные ошибки чтения, отсутствие результата и ключей после срока ожидания, принятый запрос без адреса задачи. Во всех сценариях платный POST остаётся единственным.

После установки проверен настоящий установленный worker с изолированной временной SQLite и имитацией внешнего API: ошибка ответа после готового перевода автоматически завершает задание и создаёт экспорт. Реальный внешний MT не запускался. Завершённый запуск `e23aa04f-ee92-4af0-b6a7-4e4d310ef4fa` сохранён: экспорт содержит 1 406 строк, пустых переводов нет.

Readiness визарда подтверждает database/worker ok; собственные API/worker/backup timer active. Исходные PID БДХК сохранены: API 1001139, UI 1027425, Telegram-бот 1052749, фасад 1076287; health-check успешен. Активных заданий перед установкой не было. Предыдущий выпуск сохранён для отката.
