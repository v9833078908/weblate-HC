# Исправление загрузки готовых переводов

В отдельный визард установлен runtime `3a3e2f78059e`. Работа с исходными службами БДХК и созданным Lord Ambermaze сохранена.

## Причина

После продолжения задания `2e5d00e8-3b0f-488d-b446-d3e012a15ce7` остановилась загрузка готового английского текста для `kit-3`. Weblate вернул HTTP 200, но `not_found: 208`, `accepted: 0`, `total: 208`: HTTP-успех не означал применение строк. Отправленный файл был monolingual PO с ключом в msgid; загрузка через merge не сопоставила его с реальными исходными текстами и контекстами.

## Изменение

Для готовых значений формируется отдельный bilingual PO: исходный текст в msgid, ключ в msgctxt, перевод в msgstr. Пустые значения исключены, одинаковые исходники с разными ключами сохраняются. Файл проходит точную parse-back проверку. Создание компонентов по-прежнему использует прежний monolingual формат. `conflicts=ignore` и проверка заполнения перед MT сохранены.

Версия durable-операции `seed-bilingual` позволяет продолжить старое задание, сохранив прежний ответ `seed` для аудита. Платные операции не изменены и повторно автоматически не отправляются.

## Реальная проверка и восстановление

Сделан согласованный backup `wizard-20261002T030628Z.sqlite`. Отдельно от worker под lease загружены только 208 существовавших английских значений в `kit-3` прежнего проекта. MT не запускался. Чтение API подтвердило 208/208 заполненных строк. Строгая проверка точного текста сначала остановила восстановление: сервер добавил конечные пробелы в двух строках и убрал конечную точку в одной. После проверки этих трёх точных изменений результат подтверждён исключительно GET-запросами; повторный upload не отправлялся. Подтверждение сохранено в `seed-bilingual:kit-3:en` с `observed`, `filled: 208`, `server_adjustments: 3`.

Проверены все девять немецких компонентов: значения точно совпадают с export завершённого немецкого задания. Английское задание оставлено ожидающим нажатия «Продолжить незавершённое задание». Оставшиеся компоненты и весь английский run ещё не завершены. На странице видны русское сообщение о подтверждённой загрузке и активная кнопка продолжения.
