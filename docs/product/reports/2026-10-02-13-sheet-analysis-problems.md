# Сообщения о проблемах с листами

Установлен выпуск `96ccad6031c4` независимого визарда. На шаге «Файлы» проблемный лист показывает причину и подсказку: снять галочку, если лист не нужен, либо исправить языковые заголовки. Галочки доступны; выбор сохраняется обычной кнопкой. Автоматического исключения листов нет.

В `Lord Ambermaze Localization-kit.xlsx` не распознаются языковые заголовки листов `Questions_Answers` и `General`. Первый содержит служебные заголовки `Text`, `Question/Comment`, `Answer`; второй — `Russian`, `English`, которые текущий строгий анализатор не принимает как коды языков. Остальные девять видимых листов не имеют этой структурной ошибки. Наличие ошибки заголовков не означает отсутствия текстовых данных.

API анализа дополняет лист необязательным массивом `issues` с кодом, областью и безопасным описанием. Для старых черновиков без него UI показывает общее объяснение неоднозначной структуры. Скрытые листы по-прежнему исключаются до анализа.
