# Конфликт создания языка после импорта компонента

Дата: 2026-10-02. Выпуск `release-5bfed6bcc0e8`, commit `5bfed6b`, установлен в самостоятельный визард по адресу http://192.168.0.180:18511/console/.

Задание Lord Ambermaze `e23aa04f-ee92-4af0-b6a7-4e4d310ef4fa` остановилось на этапе создания немецкого языка после успешного импорта `kit-1`. Сохранённое намерение создания языка осталось неподтверждённым. Диагностика внешнего компонента обнаружила готовый язык `de` с 13 исходными строками и пустыми переводами. Запрос создания уже существующего языка возвращает HTTP 400 с ошибкой `language_code: Could not add 'de'!`. Импорт может создавать язык между предварительной проверкой его отсутствия и запросом создания.

Клиент теперь после HTTP 400 при создании языка выполняет одну проверку GET. Если перевод существует, возвращает подтверждённый объект; если отсутствует, сохраняет ошибку. Другие отказы, в том числе HTTP 403, не маскируются. Повторного POST нет, обработка неизвестного результата платного перевода не менялась.

Регрессионные тесты воспроизвели отказ при уже созданном языке до исправления. После исправления проходят все 20 проверок backend; Ruff и проверка diff успешны. Проверка установленного клиента на том же внешнем компоненте подтверждает успешное получение существующего немецкого языка после отказа создания.

Задание не возобновлялось автоматически: его сохранённый состав включает 1 406 импортируемых строк из девяти листов, 4 008 строк карантина. Намерений машинного перевода нет. Нажатие «Продолжить незавершённое задание» восстановит прежний запуск по сохранённым операциям и может затем запустить машинный перевод всего выбранного объёма. Ранее разрешённый небольшой платный тест на пяти строках остаётся отдельным завершённым заданием.
