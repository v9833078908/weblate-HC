# Понятная причина отказа запуска

Дата: 2026-10-02. Установлен выпуск `release-7e17bb57ab26`, commit `7e17bb5`, UI http://192.168.0.180:18511/console/.

Для черновика `5c9568e6-9ffc-4a88-acb1-bfba0bff5112` источник ru и цель en подготовлены без ошибок. Сохранённый профиль проекта всё ещё содержит роль для немецкого и `language_instructions.de`: после обновления анкеты пользователь не сохранил обновлённые инструкции отдельной кнопкой. Журнал содержит успешный PATCH анкеты и отказ POST localization с HTTP 400. Новое задание не создано; прежнее немецкое задание завершено.

API правильно блокирует несовпадение языков. Интерфейс скрывал его причину общим сообщением. Теперь для ответов 4xx выводится переведённая причина API; при `profile_languages` она прямо предлагает вернуться на шаг «Контекст и термины» и нажать «Сохранить инструкции». Для сетевых и серверных сбоев сохраняется общее сообщение. Повторные запросы автоматически не отправляются. Профиль пользователя не изменялся при диагностике, реальный перевод не запускался.

Проходят 65 проверок UI, typecheck, build и diff check. Регрессионный тест воспроизвёл скрытую причину до исправления; проверены точное сообщение, fallback при сетевой ошибке, один запрос запуска и фокус ошибки. До/после установки браузер прочитал настоящий черновик, а отказ запуска имитировался на стороне браузера: запрос не поступал на сервер.
