# Сообщение о существующем глоссарии

Над выбором файла глоссария на шаге «Контекст и термины» показывается заметное сообщение: «Глоссарий уже есть в Weblate. Повторно загружать его для добавления языка не нужно. Загружайте файл только для добавления новых терминов.»

Условие: снимок подключённого проекта содержит компонент с признаком `glossary` и хотя бы одним термином. Пустой автоматически созданный глоссарий не вызывает сообщение. Проверка использует уже загруженный снимок подключения, не отправляет новых запросов к Weblate и не публикует данные. Загрузка новых терминов остаётся доступной. Подготовленный новый файл не удаляется автоматически.

Проверки: до правки новый сценарий выявил отсутствие надписи; после правки прошли 24 теста визарда, TypeScript и Vite build. Проверены порядок надписи над выбором файла, доступность сообщения, сохранение загрузки и отсутствие надписи для пустого глоссария и обычного компонента. В сохранённом снимке тестового проекта `wizard-2c0ef0fba7cf4cb9` подтверждены 197 терминов в версии глоссария.

Подготовлен отдельный пакет интерфейса `artifacts/existing-glossary-notice-ui.zip`. Серверные изменения окна наблюдения машинного перевода в него не входят.

5 октября 2026 года после отдельного разрешения пользователя интерфейс установлен на сервер 192.168.0.180. Обновлены статические файлы, исходный компонент визарда и каталог строк. Backend остаётся `release-9868b21a17d4`. Проверены контрольные суммы установленной сборки, готовность API и воркеров, вход, выдача интерфейса и прежний режим внешней записи. Сервисы не перезапускались, PID и конфигурация не изменились. Запросы к Weblate не отправлялись.
