## Причина и результат

Поле «Поиск проекта» фильтровало только список проектов локального визарда. Оно не отправляло запрос к Weblate, Enter ничего не запускал, кнопка поиска отсутствовала. Внешний Pirate Ships поэтому не появлялся на пустой локальной странице.

Добавлена кнопка «Найти» и общая обработка submit для кнопки и Enter. Поиск обращается в Weblate через GET, поддерживает часть названия и slug без учёта регистра. Локальный фильтр сохранён. Результаты внешнего поиска отделены от локальных проектов; ошибка API показывается отдельно от отсутствия совпадений. Изменение запроса отменяет предыдущий поиск, устаревшие ответы игнорируются.

«Подключить для чтения» открывает подтверждение с выбранным проектом. До подтверждения ничего не создаётся и не подключается. Подтверждение использует прежний защищённый поток локального сохранения и внешних GET. Уже подключённая внешняя цель открывает существующую карточку. Поиск совпадений в диалоге создания остаётся точным: поиск по части имени не превращает создание нового проекта в подключение похожего.
