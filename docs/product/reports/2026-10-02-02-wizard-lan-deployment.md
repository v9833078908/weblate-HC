## Исправления, выявленные при установке

1. `cp -a` переносил mode 0700 временной корневой папки в каталог выпуска; systemd завершался `200/CHDIR`. `namei` подтвердил точную причину. Установщик теперь задаёт `a+rX,go-w` только своему каталогу выпуска; секреты остаются отдельно, 0700/0600. После исправления обе службы и health/backup проверены. Commit `78125fb`.
2. Фактический импорт Weblate создал исходный язык, но не создал пустой `de` из ZIP. Добавлен стандартный POST `components/{project}/{component}/translations/` с `language_code`, с намерением перед запросом и наблюдением при восстановлении. Это не запрос MT. Контракт клиента и worker воспроизведены RED, затем весь backend прошёл 17/17. Commit `09020a6`. Существующее задание продолжено, завершён реальный перевод.

Локальные проверки после этих изменений: backend **17/17**, Ruff успешен; shell syntax успешен. UI после предыдущих изменений прошёл **57/57**, typecheck/build; в этой стадии UI-код не менялся, дополнительно проверен настоящий LAN-браузер.

Нагрузочные/длительные проверки, восстановление из backup, off-host копия и срок хранения — после запуска согласно плану. Отдельный LLM-ключ отсутствует; ручная анкета/persona/style/instructions работают. Judge/repair, новые stores/extraction/split и сообщения в выпуск не входят.

Отложенное ранее Minor не изменилось: ссылка Advanced Weblate в UI использует локальный slug. Пользователь может открыть правильную страницу нового проекта по ссылке выше; перевод и скачивание через API работают. Это отдельная небольшая правка, не расширение текущей приёмки.

Первоначальные решения и независимое ревью сохранены в `docs/product/reports/2026-10-02-local-wizard-release.md`; последующее разрешение владельца и реальная приёмка заменяют прежнее ожидание установки, имени и платного теста.
