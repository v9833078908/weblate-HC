# Сохранение предыдущих языков проекта

Причина исчезновения языка: карточка и экспорт читали только `export_pointer` последнего задания. Завершённые снимки предыдущих языков не удалялись. В Lord Ambermaze сохранены три завершённых задания одного удалённого проекта: немецкий, английский, повторный немецкий; по 1406 готовых строк в каждом. Последний указатель показывал только немецкий.

На листе UI в сохранённом английском задании исходный столбец 3 `English(en)` явно игнорируется, а перевод использует добавленный столбец 26 `en`. Эта структура возникла до данного исправления. Экспорт сохраняет исходный игнорируемый столбец и готовый перевод отдельно; перезаписи его служебных данных нет.

Выпуск `e5d2ebd6ae6b` объединяет завершённые результаты для того же владельца, локального и удалённого проекта и идентичных исходников. По каждому языку используется последний завершённый результат; порядок определяется завершением, поэтому возобновление старого задания не скрывает более новые языки. Строки сопоставляются по ключам, столбцы — по коду языка. Явно назначенные служебные и игнорируемые столбцы защищены. Исходные снимки заданий не изменяются. Карточка, сводка и скачивание используют общий накопленный результат; формат API не менялся.

## Проверка

- Сначала тест воспроизвёл потерю русского после добавления немецкого: экспорт содержал только `de`. Проверки после исправления прошли для обычного добавления, ожидания создания units и старых попыток загрузки.
- Регрессии проверяют добавляемые языковые столбцы с одинаковым исходным индексом, повторный перевод, пустые значения последнего результата, сохранность исходных снимков, защиту revision, чужого владельца, других проектов и отличающихся исходников. Два замечания ревью воспроизведены падающими тестами и устранены: возобновление старого задания и игнорируемый служебный столбец.
- Backend: 44 теста прошли; UI: 66 тестов прошли. Ruff и diff проверены. Существуют прежние предупреждения Starlette/httpx и jsdom canvas; ошибок тестов нет. Frontend не изменялся, в выпуск включена ранее проверенная сборка.
- После установки проверены реальные авторизованные GET карточки, сводки, JSON и XLSX, без подмены данных: `de` 1406/1406, `en` 1406/1406, девять листов. В браузере проверены обзор и полностью загруженная страница скачивания. XLSX прочитан обратно: девять видимых листов, на каждом столбцы ru/en/de и тексты немецкого и английского. Производственные изменяющие producer API запросы в браузере блокировались; перевод не запускался.
- Перед установкой активных заданий не было; остановлен только собственный worker, выполнен штатный backup. После установки `wizard-api`, `wizard-worker`, `wizard-backup.timer` активны, readiness сообщает database/worker `ok`.
