# Локальный выпуск внешнего визарда

Дата: 2026-10-02. Исходники: `D:\bdhc_wizard\repo`, ветка `codex/fastapi-wizard`. Production не изменён. Проверена локальная реализация; установка на сервер, реальные операции нового проекта Weblate и платный перевод ещё не выполнены.

## Что реализовано

Самостоятельный FastAPI, вход и cookie/CSRF, права владельца проекта, SQLite WAL с Alembic, перенос существующего React-визарда, сохраняемый черновик и профиль. БДХК подключён через read-only фасад с серверным Bearer-токеном; поиск, resolve, предложение изменений и отдельное подтверждение сохраняют provenance. Языковые правила показываются вместе с изменениями анкеты.

Локкит преобразуется в PO po-mono, необязательный глоссарий — в TBX. Worker использует стандартный REST API внешнего Weblate с отдельным Token, сохраняет намерение операции до POST и после неизвестного исхода наблюдает за переводами без повторного платного запроса. Возвращаемые XLSX/CSV/JSON сохраняют ключи, исходные значения, заполненные target и метаданные. Скрытые листы исключаются до анализа и отправки.

Подготовлены самостоятельные systemd-службы API/worker/backup, конфигурация, install/rollback, HTTPS-прокси и сборщик архива. Инструкция: `docs/product/guides/deployment.md`. Предлагаемый LAN-адрес после согласования и проверки порта: `http://192.168.0.180:18511/console/`. Интернет-адрес требует отдельно выбранного имени и HTTPS-публикации.

## Незавершённая реальная приёмка и ограничения

Внешний Weblate требует уникального отображаемого имени проекта. Точное имя **«тест»** сохранено по указанию владельца. Вопрос о разрешении **«тест — <короткий ID>»** для независимых повторных прогонов остаётся без ответа. Если имя занято, внешний API отклонит создание; существующий чужой проект не изменяется и автоматически не подхватывается.

Право токена создавать проект/компоненты и запускать выбранный engine ещё требуется подтвердить реальной маленькой приёмкой на новом проекте. Локальные mock-тесты и чтение списка проектов не заменяют её. Отдельный LLM-ключ не предоставлен; ручная persona/style/instructions доступна и проверена, реальная генерация не запускалась.

Этот выпуск не реализует judge/repair и не даёт заключения о качестве перевода. Статус готовности относится к получению файлов; подсчёт native failing checks Weblate не является самостоятельным quality gate этого выпуска. Исходное оформление/макросы Excel и бинарный round-trip не сохраняются. Нагрузочные/длительные проверки выполняются после запуска по согласованному плану.

## Решения исполнителя

Ниже сохранены все `Ruling:` из рабочего журнала, включая решения по областям, которые reviewer не проверял.

1. Новый проект уже изолирован отдельным Git-repo; связанный worktree чужого Weblate не создавался. Основание — прямое указание владельца. Цена ошибки: позже понадобится дополнительный worktree.
2. Владелец подтвердил локальный Git-repo; remote не придуман, corporate repo не используется. Цена ошибки: исходники пока остаются только локально, push ждёт реального remote.
3. Для русского плана/Windows использованы эквивалентные briefs/журнал вместо Bash-обёрток навыка. Цена ошибки: отсутствует автоматическое bookkeeping обёрток; RED/GREEN и commits сохранены.
4. Windows pytest использует repo-local basetemp после отказа прав во внешнем Temp. Цена ошибки: CI применит обычный временный каталог; поведение продукта не изменено.
5. Нерешённое имя тестового проекта не считается разрешением на суффикс; сохраняется точное «тест» и безопасный отказ при конфликте. Цена: повторные независимые проекты ждут решения владельца.
6. Реальные права Weblate, платный MT и production-поведение отложены до отдельно разрешённой приёмки. Цена: локальные проверки не доказывают реальную работоспособность всего внешнего контура.
7. Целевая установка/сеть/backup проверены статически; команды production не выполняются до этапа 7. Цена: особенности целевого окружения могут потребовать правок при установке.
8. Нагрузка, длительные обрывы и стресс многих пользователей отложены по указанию владельца; подтверждённые нарушения lease исправлены сейчас. Цена: эксплуатационные пределы ещё не измерены.

## Отложенное Minor

Ссылки «Advanced Weblate» в карточке проекта используют локальный slug, тогда как удалённый проект получает run-суффикс. После успешного реального прогона такая ссылка может вести на 404. Получение перевода и скачивание через API не зависят от неё; исправление ссылки оставлено отдельной небольшой задачей. До исправления открыть внешний проект можно по сохранённому `summary.remote_project` задания.

## Следующее действие

Согласовать готовый архив и точный сетевой адрес, решить имя повторных тестовых проектов. Затем выполнить этап 7: записать старые PID/health и свободный порт, установить только новый сервис, проверить UI/API с рабочего компьютера. Платная приёмка — отдельные 5–10 подтверждённых строк, один выбранный target и заранее согласованный объём. До этого новый адрес не объявляется работающим.
