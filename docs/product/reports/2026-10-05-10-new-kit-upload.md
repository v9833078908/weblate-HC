# Загрузка новой версии лок-кита в существующем проекте

Статус: установлено на сервер 192.168.0.180 2026-10-05 в 10:30 UTC.

Кнопка «Загрузить новый лок-кит» открывает выбор файлов у восстановленного черновика на шаге «Файлы». Успешная загрузка использует существующий API создания отдельного черновика, возвращает на первый шаг, сбрасывает прежнее сравнение и ссылку на файл глоссария. При ошибке исходный черновик и адрес сохраняются. Выбор файла не запускает локализацию.

Сравнение, подтверждение, сохранение внешних переводов и запрет изменения исходного текста под существующим ключом работают по прежним правилам. При установке запросов записи в Weblate не было.

Проверено: 96 тестов интерфейса, TypeScript, каталог gettext и сборка Vite. Два новых теста проверяют отдельный токен и сброс g после успешной загрузки, сохранение исходного черновика при ошибке и повторный выбор файла. В accessibility-тестах остаётся прежнее предупреждение jsdom о canvas.
