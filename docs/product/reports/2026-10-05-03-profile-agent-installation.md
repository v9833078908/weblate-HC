## Проверка агента на сервере

Проверка выполнена установленным кодом и настройками фактического API-процесса на отдельной копии базы. Production API и профильный worker проверены по readiness и heartbeat. Изолированный smoke вызывает тот же обработчик очереди напрямую; он не добавляет тестовое задание в production-базу.

Реальная карточка БДХК прочитана без передачи её приватных фактов в модель. Полное название «Dead Shell・Pixel RPG Roguelike» совпало автоматически. Для короткого «Dead Shell» получен `choice_required`; явный выбор найденной карточки успешно заполнил контекст. Первый запуск проверки ошибочно ожидал точное совпадение для короткого названия и остановился до LLM-вызова. После сверки фактического названия скорректирована только проверка.

Один реальный запрос OpenRouter отправлен с публичными синтетическими фактами и искусственной исходной строкой. Перед отправкой проверены реальные заголовки:

```text
X-OpenRouter-Title: HCGameLoc Wizard - Translation Profile Agent
HTTP-Referer: http://192.168.0.180:18511/console
```

Ответ `openai/gpt-6-luna`: 1242 входных и 674 выходных токена. Получены непустые роль и стиль, инструкции для точных кодов `zh_Hans`, `zh_Hant`, `ja`, `pt_BR`, `es_MX`. Задание стало `ready`, `auto_saved: true`, сохранённый профиль совпал с результатом.

Повторная подготовка вернула тот же идентификатор готового задания; второй модельный запрос не отправлялся. Ручная правка стиля сохранилась с источником `manual` и отобразилась при повторном чтении. На сервере оставлен закрытый журнал проверки `shared/backups/profile-server-smoke-20261005.json`. Существующие пользовательские проекты, профили и лок-киты не изменены этой проверкой.

LAN-проверка сначала ожидала неверное имя DOM-контейнера `root`; проверка исправлена на фактический `producer-console-app` без изменения приложения и повторена успешно.
