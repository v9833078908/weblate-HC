# Восстановление лок-кита после истечения черновика

Статус: установлено 2026-10-05 в 11:00 UTC на сервер 192.168.0.180.

Причина пустой формы: активный черновик живёт один час, затем удаляется обслуживанием вместе с временной загрузкой. Постоянная версия с оригиналами остаётся, но старая форма её не восстанавливала. В указанном проекте временных черновиков уже не было; приватные оригиналы версий присутствовали.

При входе без u форма запрашивает активную загрузку; после 404 выполняет локальный POST /api/producer/projects/{slug}/uploads/restore/. API проверяет сессию, CSRF и владение проектом, выбирает последнюю обычную версию, проверяет приватные пути и восстанавливает новый черновик из оригиналов. Сохраняются листы, язык источника, выбранные цели и манифест; первое открытие восстановленной версии начинается с шага «Файлы». Глоссарии исключаются. Новые записи версий дополнительно сохраняют ответы и карту имён оригиналов. Старые версии сопоставляются по листам и заголовкам; неоднозначное совпадение запрещено.

Над кнопкой «Загрузить новый лок-кит» показано пояснение: «Используется загруженный лок-кит. При необходимости можно загрузить новую версию кнопкой ниже».

Проверены пять серверных регрессий: восстановление после очистки, старый формат версии, разграничение владельца и проекта, исключение глоссария, приватные пути, сессия/CSRF маршрута. Проверен сценарий формы с просроченным активным черновиком и сохранением языка при переходе дальше. Весь интерфейс: 97 тестов, TypeScript и сборка прошли. Ruff прошёл. Финальный полный серверный набор: 188 тестов прошли.

Перед установкой на изолированной копии настоящей базы и приватных файлов проекта wizard-2c0ef0fba7cf4cb9 восстановлены 963 строки, один выбранный лист и источник ru. Повторный patch выбора сохранил source_identity. Затем через рабочий API восстановлен локальный черновик того же проекта; GET active вернул тот же токен и 963 строки. Внешних запросов записи или запуска перевода не было.
