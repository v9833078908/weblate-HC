# Локальный выпуск агента подготовки инструкций

Дата: 2026-10-05. План: docs/product/plans/2026-10-05-game-profile-agent.md. База: 389f7005a2660fc514002dcade1e93f66a2248c2, ветка codex/persistent-projects. Репозиторий визарда не имеет Git remote; коммиты сохраняются в исходном репозитории и source bundle.

## Что реализовано

FastAPI автоматически сопоставляет имя проекта с единственной точной карточкой БДХК. Связанный title_id имеет приоритет; неточное или неоднозначное имя требует выбора. Снимок карточки принадлежит владельцу и конкретному лок-киту. Ручной поиск по имени/ссылке сохранён.

Один запрос GPT-5.4 mini через OpenRouter подготовлен для роли, стиля и всех выбранных языков. Три собственных версионированных навыка: факты игры, промпт локализации, особенности локали. Имеются 14 компактных справок с источниками, точные коды и различение zh_Hans/zh_Hant, pt/pt_BR, es/es_MX. Примеры берутся только из исходной колонки выбранных листов. Полный вход ограничен 24 000 символами.

SQLite-очередь и отдельная служба выполняют подготовку независимо от вкладки. Строгая схема и лимиты проверяются локально; правила движка добавляются кодом. Готовый результат и профиль сохраняются одной транзакцией. Повторное открытие не создаёт новый запрос для того же содержимого; результат после сбоя публикации восстанавливается без сети. Неизвестный результат отправленного запроса автоматически не повторяется.

Форма содержит требуемый заголовок, редактируемые инструкции и автоматическое сохранение. Кнопка сохранения нужна только для ручных изменений. Отдельное поле «Роль игрока» удалено из текущей формы, старые значения сохраняются. Ручные правки защищены происхождением и ревизией; другие языки профиля сохраняются. Поздние ответы и данные другого черновика не публикуются поверх текущих.

Установщик, полный бэкап, preflight, readiness и откат учитывают отдельный генератор. После неудачной установки/отката до запуска старого API атомарно отключаются агент, прежний синхронный LLM-путь и внешняя запись. Конфигурация сохраняется приватно для повторного явного подключения.

- Полный UI: 90 тестов прошли (до изменения 82).

- Реальный локальный браузер с синтетической карточкой: desktop и 390 px без горизонтального переполнения страницы, автосохранение, тот же job после обновления, ручной текст сохраняется после повторного открытия; ошибок JavaScript нет.
- Автоматические проверки доступности новой формы не нашли serious/critical нарушений; проверены подписи, клавиатурные действия и фокус ошибки.
- На изолированных копиях проверены полный бэкап/восстановление, сохранение UI/очереди и совместимость дополнительных Record-kind с прежней версией.

Сохраняются прежние предупреждения Starlette TestClient/httpx и jsdom canvas; ошибок проверок нет.

Один независимый обзор всего изменения выявил пять существенных проблем; все исправлены за один проход с воспроизводящими тестами RED→GREEN: устаревший индекс задания, происхождение ручного контекста, обход лимита карточки/входа, старый платный путь при неудачной установке, потеря подтверждённых правил игры в базовом шаблоне. Повторный обзор не запускался.

## Принятые решения

1. На Windows служебный журнал и задания ведутся через PowerShell/Python вместо POSIX-хелперов с английскими заголовками. Возможная цена ошибки: форма служебной записи, без влияния на продукт.
2. Атомарная публикация перенесена из задачи 4 в задачу 3, чтобы ready сразу означало сохранение. Возможная цена ошибки: только разбивка задач по модулям.
3. Старый ProfileIntegration оставлен для совместимых клиентов без нового API точного черновика; текущий визард использует новую форму. Возможная цена ошибки: старые клиенты продолжают видеть старые подписи.
4. Откат отключает также прежние MODEL/TOKEN_FILE и внешнюю запись, чтобы старый API не сделал платный синхронный вызов. Возможная цена ошибки: администратор должен явно подключить настройки снова.

Отложенных мелких замечаний обзора нет.
