# Языки в ранее сохранённом шаблоне

Дата: 2026-10-02. Установлен выпуск `release-0c015cfd40db`, commit `0c015cf`, по адресу http://192.168.0.180:18511/console/.

При повторной локализации Lord Ambermaze с выбранным английским языком роль продолжала указывать немецкий из прошлого запуска. Причина: любое сохранённое значение целиком считалось ручным и переставало обновляться. Регрессионная проверка воспроизвела эту ошибку до исправления.

Теперь распознаваемое шаблонное предложение «Переводи тексты … с … на …: интерфейс, диалоги и игровые описания.» получает актуальные название проекта и языки. Прочие предложения роли, добавленные пользователем, и стиль сохраняются. Произвольная роль без такого предложения не переписывается. При неполной загрузке языков сохранённый текст остаётся до получения выбора. Сохранение через кнопку «Сохранить инструкции» по-прежнему необходимо; автозаполнение не выполняет запись или перевод.

Проходят 63 проверки интерфейса, typecheck, build и diff check. Новая проверка охватывает сохранённый немецкий шаблон → английский, позднюю загрузку выбора, несколько целей, смену исходного языка и названия, сохранение ручных дополнений и отправку обновлённого текста в API.
