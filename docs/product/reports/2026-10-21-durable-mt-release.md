# Выпуск устойчивого машинного перевода

21 октября 2026: Weblate и визард обновлены, обработка выполняется штатными
workers. Это MT-релиз, не выпуск quality v2 и не подтверждение полного цикла
двух судей, глоссария и повторов.

## Результат

- Weblate: runtime-коммит `292519649758fae30809b12a88239cc3fe2c2e22`,
  образ `hcgameloc:durable-mt-29251964`, миграция `0147_producer_mt_operations`.
  Образ дополняет точный старый runtime десятью Python-файлами без смены зависимостей.
- Визард: коммит `12c43e255c57d1e83167c239a6ea98f16c01423c`, release
  `release-12c43e2-durable-mt-20261021`; схема SQLite осталась `0001`.
- Новый режим включён только для проекта `wizard-eea5f3f3af874c85-8add8aa4`,
  в задании выбран только немецкий язык.
- Исходно 1662 строки: 550 готовых, 1112 пустых. Первый новый пакет завершён:
  подтверждено 570 готовых / 1092 пустых. Визард сам принял следующий пакет.
  Это промежуточный результат, не завершение всего задания.
- Исходные 550 targets/states, остальные языки, источники и контексты точно
  совпали со снимком после выпуска и после первого пакета.
- Последний старый запрос с неизвестным исходом сверён: все его строки уже
  заполнены. Старый recovery-процесс завершён, журнал сохранён, пакет не повторён.

Визард сохраняет ключ и опрашивает ту же операцию после тайм-аута. Weblate
сохраняет намерение по каждой ревизии и ответ до применения. Изменённые и
непустые строки защищены. Неизвестный исход провайдера не разрешает повторную оплату.

## Проверки и границы доказательств

- Точный серверный кандидат визарда: 272 теста, Python 3.14 Linux, без реальных
  credentials и внешних соединений. UI: 106 тестов, typecheck и build прошли.
- Weblate: 38 новых MT-тестов, 21 тест Producer API; затронутые регрессии —
  1720 passed / 53 skipped. Для 22 старых HTTP-mock тестов закрытой среды
  применена отдельная подстановка публичного DNS, не изменение продукта.
- Локальный E2E: 1662 синтетические строки, 550 защищённых, 1112 уникальных
  новых запросов по строкам / 56 пакетов, потеря 202 с 504, сохранение checkpoint
  и повторная доставка. LLM в нём подменены; первый реальный пакет проверен после выпуска.
- Независимый read-only reviewer: шесть существенных находок исправлены через
  RED/GREEN — внутренние повторы LLM, откат, отмена, кэшированный префикс,
  конкурирующее восстановление lease, исчерпание публикации в брокер.
  OpenAPI также сгенерирован и проверен. Отложенных minor-замечаний нет.
- Весь Weblate **не зелёный**: 329 разрешимых сбоев воспроизведены на исходном
  серверном коде. Один первоначальный glossary UI сбой не повторился в свежем
  классе; другой сбой класса одинаков на обеих версиях. Полный прогон оборвался
  внутренней ошибкой xdist и не завершён. Несвязанные сбои не исправлялись.
- Windows-прогон, оборванный access violation интерпретатора, не засчитан как
  успех. Окончательный полный прогон визарда подтверждён на Linux.
- Конкуренция проверена повторной доставкой, повторным входом worker и
  моделированием взаимного восстановления. Отдельного нагрузочного прогона
  двух реальных параллельных HTTP/worker-процессов не было.

В production при остановленном переводчике дважды принят один пакет с одним
ключом: тот же run, 20 pending, применено 0. Первый запрос занял 5,127 с,
повтор — 0,207 с. Нельзя утверждать, что первый production-приём уложился в 2 с.
После передачи штатному worker пакет завершён без повторного перевода готовых строк.

Host nginx: 660 с только для нового MT route; container nginx: существующие
3600 с. Независимый TLS edge не проверен и не перенастроен. LLM больше не
удерживает HTTP-запрос приёма пакета.

## Принятые решения

1. Revision использует wire-массивы source/target для общего контракта.
   Цена ошибки — ложный stale всех строк.
2. Клиентский RED/GREEN выполнялся при подготовке окружения Weblate.
   Контракт сохранён; риск несовместимости закрыт совместным E2E.
3. Визард выпускается узким backport от реального server baseline, без quality v2.
   Цена — отдельный будущий выпуск полного quality-цикла.
4. GET использует лимит чтения, POST сохраняет producer 60/hour. Опрос не
   съедает бюджет приёма; цена — нагрузка чтения остаётся на общем лимите.
5. Новая Celery identity и неизвестная старому outbox execution-version
   защищают откат. Старый worker может отклонить сообщение; после обновления
   требуется безопасно опубликовать pending receipt, а не новый платный запрос.
6. Несвязанные baseline failures оставлены. Цена — полный набор остаётся
   проблемным; целевые результаты не объявляются полным зелёным прогоном.
7. Exactly-once оплата провайдера не обещается. Цена fail-closed — возможное
   ручное выяснение provider_unknown вместо автоматической повторной оплаты.
8. Reviewer не подтверждал production credentials, rollout, backups и proxy.
   Исполнитель проверил их отдельно; недоступный edge остаётся ограничением.
9. Plural sources отклоняются, quality v2 не включается. Цена — отдельная
   реализация/проверка этих возможностей, не обещание полного цикла по заполненности.
10. Четыре файла baseline визарда различались только CRLF/LF: проверены точные
    нормализованные SHA. Семантическое расхождение запрещено, исходные байты в бэкапе.
11. Overlay точного runtime не меняет зависимости. Цена — будущий deploy
    должен учитывать отдельный Compose override.
