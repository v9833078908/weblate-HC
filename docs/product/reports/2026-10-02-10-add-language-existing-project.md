# Добавление языка в существующий проект

Установлен runtime `5cbb99b04c56` в `/opt/bdhc/weblate-wizard/releases/release-5cbb99b04c56`. Изменены только собственные службы визарда. Работа БДХК сохранена.

## Причина и исправление

Повторный запуск Lord Ambermaze с target `en` пытался создать новый проект с тем же названием вместо использования созданного при немецком переводе. Основной контракт Weblate требует уникального имени; прежний проект существует, предложенный новый slug отсутствует. Ошибка создания HTTP 400 оставила intent, из-за которого продолжение запрещало повторный запрос.

Теперь завершённый импорт того же владельца и локального проекта определяет существующий remote project. Визард сверяет исходный язык, компоненты, ключи и исходные строки с прежним snapshot, затем проверяет реальные исходники Weblate перед обработкой и при продолжении. При несовпадении импорт блокируется. Компоненты повторно не создаются и исходники не перезаписываются. Добавляются выбранные языки, заполненные значения лок-кита предварительно загружаются с `conflicts=ignore`; готовые значения Weblate сохраняются, включая итоговый экспорт. Новый глоссарий при расширении пока не поддержан; существующий сохраняется.

Запуск/продолжение резервируют локальный проект в транзакции. Другое активное задание или failed-задание с неподтверждённым платным MT блокируют новый запуск. Неизвестный результат платного MT не вызывает повторный POST. Явный HTTP 400 у неплатной операции создания сохраняется как отказ, отдельно от неизвестного результата.
