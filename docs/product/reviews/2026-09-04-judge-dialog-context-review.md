# Ревью плана «соседние реплики диалога в контексте судьи»

Дата: 2026-09-04. Предмет: `docs/llm-first/plans/2026-08-20-judge-dialog-context.md`
(статус «ожидает одобрения» с 2026-08-20, не реализован). Вердикт и замер ниже;
переписанный план - тот же файл, статус и дата в его шапке.

## 1. Состояние кода на HEAD

Ничего из плана не сделано, и код с 20.08 ушёл от того, против чего план
писался:

- `JudgeRequest` (`weblate/trans/judge.py:192`) - без полей соседей; `_segment`
  (`judge.py:901`) сериализует `id, key, source, target, rendered_*, note,
  explanation, glossary, checks`. Поле `explanation` появилось 31.08
  (`98a0b57`), план о нём не знает.
- `compute_context_hash` (`weblate/trans/models/judge.py:220`) хеширует
  `source, note, explanation, glossary_terms`. Вызывается из **16** мест в
  продовом коде, не из одного: `models/judge.py:918`
  (`_current_snapshot_hashes` -> `current_round`, вся UI-свежесть),
  `judge_loop.py:298/392/508/514/578/584/598/693/1714/1979`,
  `views/basic.py:764`, `views/edit.py:1376`, `autotranslate.py:906/1300`.
  План (задача 4) меняет сигнатуру и одно место заполнения.
- `_prompt_schema_version()` (`judge.py:413`) - фингерпринт байтов
  `verdict.txt`; входит в `compute_judge_request_identity`, по которому
  работает `_cached_verdict`. Любая строка в промпте обнуляет кэш-попадания
  для всех юнитов; «байт-идентичный hash без соседей» спасает только
  `current_round`, не переиспользование вердиктов.
- Драйвер `analysis/probes/st2-zh-recalibration.py` носит собственную копию
  промпта арма D (`SYSTEM_PROMPT`, строка 88) и собственный `render_segment`
  без `explanation`/glossary-флагов. Продовый `verdict.txt` после 20.08
  менялся трижды (`2e358cb`, `c979bbc`, `98a0b57`). «Строка байт-в-байт из
  измеренного плеча H2» из этого драйвера невозможна.
- Плечо H измерялось на OpenRouter (`deepseek/deepseek-v4-pro`,
  `qwen/qwen3-235b-a22b-2507`). Прод: LiteLLM-прокси, seat 1
  `deepseek-v4-pro` (batch 2, reasoning on), seat 2 `atlas/qwen3.8-max`
  (batch 1, `extra_body.enable_thinking=false`) -
  `dev-docker/docker-compose.yml:71-117`.
- Промпт получает коды языков (`build_request` подставляет
  `source_language.code`): продовый системный промпт читается как «a ru to fr
  video game localization ... translated back into ru». Не предмет этого
  плана, но зафиксировано, потому что попало в замер ниже.

## 2. Корпус плана не содержит диалога

`analysis/data/st2-zh-units.jsonl`: 124 ключа `ID_USER_*`, `ID_CARAVAN_*`,
`ID_DIVISION_*`, `ID_RANK_*`; ни одного `DIALOG|SPEECH|LINE|STORY`. Гейты
G2/G3 («REAL не ниже H») на UI-корпусе могут показать только отсутствие
вреда; пользу окна ±1 они показать не могут. Мотивирующие кейсы плана -
сцены `heart-abyss/hub-1`.

Структурная оценка «зависимости от соседа» по эвристикам (начало с союза или
строчной буквы, многоточие в начале, незакрытая предыдущая реплика,
дубликат исходника), скрипт в чате, воспроизводим по описанию:

| Корпус | Юнитов | Зависимых | Из них |
|---|---|---|---|
| hub-1 (диалог, 396) | 396 | 170 (43 %) | союз в начале 86, дубликат исходника 52, <=2 слова 44 |
| st2-zh (UI, план) | 124 | 39 (31 %) | почти всё - <=2 слова (метки) |
| nfg-ui-fr (UI) | 466 | 235 (50 %) | 225 - <=2 слова (метки) |

## 3. Замер

`docs/llm-first/measurements/2026-09-04-judge-dialog-context-paired.md`:
109 юнитов трёх сцен hub-1 (fr), продовые сиденья, продовые helper'ы,
плечи H/H2 с одинаковыми батчами. Seat 2 - нулевой эффект на вердикты за
+9 % входа; seat 1 - разница внутри шумового пола, сосед процитирован в
1 описании из 17, за +10 % входа, +15 % выхода, +13 % времени. Оба
мотивирующих ложных срабатывания (`teahouse_1_11`, `first_1_3`) остаются
critical при дословно поданном соседе.

## 4. Решение

План **отклонён**: гипотеза измерена и не подтвердилась; код не меняется.
Файл плана переписан в запись решения (что установлено, что переоткроет).
Сопутствующие правки: статус в
`docs/llm-first/vision/llm-first-product-architecture.md`, пометка в
поправке 2026-08-20 дизайн-дока.

Отдельно, вне плана: промпт судьи получает коды языков вместо названий
(`build_request`, `judge_loop.py:117-118`) - мелкая правка для другого
среза.
