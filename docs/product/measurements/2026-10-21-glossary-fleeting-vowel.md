# Беглая гласная: русские термины, которые матчер глоссария не видит

Дата: 2026-10-21. Только чтение прода, без запросов к моделям, $0.

Проба: `analysis/probes/glossary-fleeting-vowel.py`.
Вывод: `analysis/data/glossary-fleeting-vowel-2026-10-21/summary.json`.

## Повод

Pirate Ships, EN: в одной игре «Стрелок» переведён как Shooter и как
Rifleman. В глоссарии `Стрелок -> Shooter`, но строку
`tutorial_hint_rifleman_card_select2` («Выбери Стрелка... Стрелков лучше
прятать...») MT перевёл как «Choose a Rifleman... Riflemen» три раза подряд
(2026-09-12, 2026-10-06, 2026-10-07). Термин не попал в промпт: Snowball
режет только окончания, а у «стрелок» в косвенных падежах выпадает гласная.

```text
стрелок -> стрелок    стрелка/стрелков/стрелки -> стрелк
боец    -> боец       бойца/бойцов/бойцами    -> бойц
уровень -> уровен     уровня/уровней          -> уровн
```

Тот же матчер кормит промпт MT, проверку глоссария и судью, поэтому все три
слепы к таким строкам одновременно. Вес этого измерен раньше: на COL4 термин
в промпте соблюдается в 478 из 478 случаев, выпавший - в 283 из 368
(`docs/product/measurements/2026-08-11-glossary-enforcement-analysis.md`,
пункт 10).

## Метод

Все русскоязычные проекты прода, кроме `wizard-*` и `test-*`: исходники
контентных компонентов и термины глоссариев через API. Слова и аббревиатуры
режутся тем же кодом, что в `get_glossary_stem_automaton`; флаги терминов не
читаются. Сравнивались три способа сопоставления поверх сегодняшнего Snowball:

- **A, правило** - `weblate.checks.morphology.stem_alternatives`: основа вида
  «согласная + о/е/ё + согласная» получает вариант без гласной (и с «ь» для
  е/ё), «гласная + е + согласная» - вариант с «й». Вариант короче четырёх букв
  отбрасывается.
- **B, лемматизатор** - pymorphy3 вместо Snowball с обеих сторон.
- **C, парадигма** - pymorphy3 только на стороне глоссария: термин читается
  как именительный падеж, все его формы той же части речи режутся Snowball и
  попадают в индекс; строки по-прежнему режет Snowball.

## Результат

Snowball сегодня находит 11 156 вхождений терминов.

| проект | строк | Snowball | A: +вхождений / +строк | C: +вхождений / +строк |
|---|---|---|---|---|
| anvil-saga | 9 482 | 4 706 | 149 / 148 | 267 / 260 |
| col4 | 4 023 | 2 427 | 35 / 35 | 78 / 75 |
| dead-shell | 963 | 661 | 21 / 21 | 44 / 43 |
| heart-abyss | 5 111 | 1 090 | 1 / 1 | 79 / 75 |
| need-for-greed | 922 | 905 | 24 / 23 | 45 / 43 |
| pirate-ships | 4 119 | 1 009 | 49 / 38 | 75 / 63 |
| victory-banner | 619 | 358 | 3 / 3 | 28 / 26 |
| **итого** | | **11 156** | **282 / 269** | **616 / 585** |

**A.** Возвращает `Купец` (купца, купцы, купцов), `Замок`, `Беженец`,
`Уровень`, `Стрелок`, `Боец`, `Торговец`, `Камень`, `Костёр`, `Паёк`,
`Котёл`, `Молоток`. Ложное одно: `Серёга <- сергей` (2). Порог в четыре буквы
снял `Игорь <- игры/игру` (21), `Осень <- основ` (2) и `умение <- умные` (4);
вместе с ними ушёл один верный случай, `нефритовый угорь <- нефритового
угря` (2).

**B.** +529 и одновременно −505 против Snowball. Теряет верные совпадения
(`золотых`, `большой пушки`, `захватить`) и ошибается на самом термине:
первый разбор «стрелок» (0,67) - родительный падеж множественного числа от
«стрелка», поэтому «стрелков» не находится. Как замена Snowball отклонён.

**C.** Сверх A закрывает второй класс: Snowball неверно режет сам термин в
именительном падеже, и косвенные формы с ним не совпадают.

```text
монах -> мон      монахи -> монах
опыт  -> оп       опыта  -> опыт
арена -> ар       арену  -> арен
колизей -> колиз  колизея -> колизе
крестьянин -> крестьянин   крестьяне -> крестьян
кружка -> кружк   кружек -> кружек
```

Это `Крестьянин` (59), `Колизей` (19), `Монах` (35), `Кружка`, `Подкова`,
`Бочка`, `Опыт`, `Время`, `Знамя`, `Ячейка`. Ложные по верхушке списка -
около 10-18% добавленного: короткие основы из форм парадигмы (`лисёнок <-
лис`, `Весна <- вес`, `статуя <- стать`, `Могилы <- могу`) и однокоренные
(`Кухня <- кухонный`, `Раменная <- рамен`). Доля оценена по верхним 90
формам, не полной разметкой.

## Решение

A внедрён (`stem_alternatives` в `weblate/checks/morphology.py`, индекс в
`weblate/glossary/models.py`, подсчёт вхождений в `count_inflected`): почти
без ложных, без зависимостей. В отпечаток матчера добавлено поле
`fleeting_vowel_min_stem`, поэтому замеры до и после правки различимы.

C даёт вдвое больше строк, но требует pymorphy3 со словарём (17 МБ) в образе
и фильтра коротких основ. По правилу из замера 2026-08-11 лемматизатор
вводится только после A/B-прогона на выходе пайплайна, без новых hard.
Отложен до такого прогона.

## Воспроизведение

```sh
uv run --with pymorphy3 python analysis/probes/glossary-fleeting-vowel.py
```

Без pymorphy3 считаются только Snowball и A.
