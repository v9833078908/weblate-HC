Документ для сверки с командой игры. Заменяет версию от 2026-09-24
(`docs/operations/plans/2026-08-15-pirate-ships-production-cleanup-json-migration.md`,

## Что изменилось с 24 сентября

- Ветки `2026-09-15_beta` больше нет. Сверка сделана с
  `2026-10-05_release_1.45.2_table_update` (`d0514ed`). От `master`
  (`d9a518b`) она отличается только двумя RU-строками
  (`clan_offer_card_gift_label`, `territorial_wars_panel_rules`) и
  30 переводами к ним.
- Заморозки не было, обе стороны продолжали меняться:
  - в Weblate с 24.09 около 3 400 изменений, ключей 3 936 вместо 3 914;
  - в файлах игры после 24.09 изменено 52 RU-строки мимо Weblate
    (туториальные подсказки обёрнуты в `<b>…</b>` и др.).
- Расхождений стало вдвое больше: 1 285 ячеек вместо 595.
- Компонент Weblate по-прежнему не подключён к Git (`vcs=local`, без push).
  Ветка `localization` на smoke-коммите `f36580f` от августа.

## Что сейчас не так

«Weblate источник правды» значит: переводы меняются только в Weblate, а
файлы в игре - лишь копия того, что в нём лежит. Сейчас файлы релизной
ветки и Weblate расходятся в обе стороны:

- **Переименования мимо Weblate.** 274 диалога переименованы
  `dialog_*` -> `dialogue_*` прямо в файлах. В Weblate они под старыми
  именами.
- **Новые ключи мимо Weblate.** 155 ключей есть в файлах, в Weblate их
  нет. 12 из них (`description_resourse_tips_*`) пусты во всех 15 языках -
  в игре вместо текста будут сырые ключи.
- **Ключи только в Weblate.** 26 ключей есть в Weblate, но нет в файлах.
  Часть - удалённые в игре (`update_1_43_info_*`, `update_text`,
  `ShopCardPromoTapjoy*`), часть - похоже, новый контент, ещё не
  перенесённый в игру: хэллоуинская распродажа (`halloween_shop`,
  `offer_halloween_sale_point`, `shop_event_title_halloween_sale`),
  Battle Pass капитана 7 (`battle_pass_captain7`, `bp_captain7_*`,
  `ability_*_crew_captain_bp_7_*`). **Нужно подтверждение команды:**
  какие из 26 удалить, какие перенести в игру.
- **Правки RU в файлах.** 50 RU-строк поправлены в файлах; в Weblate их нет,
  и 677 переводов в Weblate сделаны по старому RU.
- **Правки не возвращаются в игру.** Августовский cleanup Weblate
  (`...` -> `…`, пробелы, разметка) в файлы не попал.
- **Английский текст в RU Weblate.** У `daily39_description`,
  `cbp_use_amulet_battle`, `cbp_use_amulet_battle2`,
  `tw_item_name_building_portal` русский исходник заменён английским.
  Причина - скилл `weblate-push-translate`: команда «обнови перевод»
  пишет значение в RU, а не в язык перевода.

Главный вывод не изменился: **если сейчас включить push из Weblate, игра
сломается** - в файлах не будет 429 используемых ключей (274 + 155).

## Как будет работать

```
скилл "добавь ключ" --API--> Weblate --push--> ветка localization --перенос + проверка--> релизная ветка --> master
                               ^
              переводчики, машинный перевод, судья
```

Файлы локализации в релизной ветке и `master` никто не правит, ни человек,
ни скилл. Они меняются только переносом из `localization`:

```sh
git fetch origin localization
git checkout origin/localization -- 'Assets/Resources/Data/Localization_*.json'
# проверка, затем
git commit -m "chore(l10n): sync from localization <sha>"
```

## Изменения скиллов

| Скилл | Что мешает | Что сделать |
| --- | --- | --- |
| `weblate-push-translate` | Пишет `Localization_*.json` локально, человек коммитит: второй писатель. Правку перевода пишет в RU | Оставить только API-часть, убрать запись файлов. Правка перевода меняет язык перевода, не RU. После перевода - push через API: `POST /api/components/pirate-ships/<компонент>/repository/` с `{"operation": "push"}` |
| `validate-localization` | Отправляет RU из локального файла в Weblate и откатывает свежий RU; пишет файлы | Только проверка файлов ветки `localization`, без записи. Это и есть барьер перед переносом |
| `migrate-legacy-localization` | Прямое копирование в обход Weblate - источник «невидимых» ключей | Удалить |
| Переименование и удаление ключей | Скиллы этого не умеют, поэтому делали в файлах | Через API: новый ключ плюс `DELETE /api/units/<id>/` для старого, либо писать нам |
