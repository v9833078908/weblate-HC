## Данные и резервные копии

Повторная сверка 18 групп component/language, 39 квитанций и старого job не
показала изменений. На production сохранены 1310 непустых целевых de-переводов;
это отдельный production scope, не исторический локальный scope 1662 переводов.
Job остаётся unknown, без активной аренды, с тем же исходным payload.
Все production-контейнеры сохранили ID/image/start/restart state.

Актуальный online pg_dump сохранён в приватной локальной папке, SHA проверен:
147338533 байта, `17ee41fe46b206f19f25b7e8c03e887c401579a83d3e06e9cfa219509ae12c97`.
Его восстановление ещё не проверено; это не B0/B1 и не полный согласованный backup.

Экспорт текущего image отменён: внутренний staging Docker при docker save
снизил свободное место примерно с 2,89 до 0,98 ГиБ. Остановлен только наш
процесс docker save с проверкой точного argv/image; контейнеры не останавливались.
Docker освободил staging: снова 3105427456 байт (2,89 ГиБ). Неполный локальный
архив сохранён с суффиксом `.partial` и для восстановления непригоден.
Утверждение «потоковый save не расходует диск сервера» неверно: отдельный
архив на сервере не создавался, но внутренние временные файлы занимали место.
Повторный save требует достаточного запаса или отдельно проверенного способа.

## Следующие условия

После read-only проверки согласовать включение актуальных коммитов, затем
повторить пересекающиеся тесты и сборку. Отдельно согласовать точный allowlist
освобождения места. Сначала получить полный проверенный rollback image и
актуальные резервные копии. В разрешённое окно: остановка писателей, B0,
изоляция без возобновления, B1, обновление Weblate, затем Wizard с выключенными
внешними записями. Приёмка данных и квитанций предшествует разрешению новых задач.
Production не обновлялся, сервисы не перезапускались, старое задание не возобновлялось.
