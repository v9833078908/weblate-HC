# Сквозная проверка обновлённого локального стенда

**Результат:** браузерные сценарии и два прогона обработки с подставными
ответами прошли. Production не подключался, платных запросов нет. Код продукта
не менялся; внешняя запись и LLM-агент ручного стенда остаются выключенными.

Проверен код Weblate `970bd2945f18737f543e41f217d3ec045b9a5473` и Wizard
`91fe4e90add625b4be5d1c247f360c9cad541b6b`, запущенный на ручном стенде.
Последующие коммиты веток содержат документацию, не меняющую runtime-код.

## Браузерная проверка на работающем стенде

На `https://127.0.0.1:19443/` и `https://127.0.0.1:19444/` пройдены:

1. Вход через Weblate, согласие OIDC и возврат в визард.
2. Создание отдельного синтетического проекта и загрузка XLSX с двумя листами.
3. Выбор исходного английского, польского и традиционного китайского; отсутствие
   дублирующихся языковых карточек.
4. Автосохранение базовых инструкций без LLM, ручная правка и её сохранность.
5. Подготовка тестового глоссария без публикации в Weblate.
6. Подтверждение шести строк и одной подстановки русского исходника при пустом
   английском. Проверено сохранение плейсхолдера `{0}` в manifest.
7. Запрет платного старта: кнопка отключена, прямой POST возвращает 403.
8. Повторное открытие локкита и сохранённых языков, возможность загрузить новый файл.
9. Выход и отказ доступа по отозванной сессии.

Дополнительный связанный сценарий начался из меню самого Weblate: вход,
переход по ссылке визарда, согласие SSO, загрузка CSV из двух строк, выбор en/de,
автоматические инструкции и переход к проверке. Именно этот черновик, исходный
файл и сохранённый профиль использованы в последующем тесте обработки.
Браузер не получил ошибок JavaScript и не обращался за пределы двух local origins.

## Завершение обработки с тестовыми ответами

Чтобы не включать платные функции ручного стенда, после браузерной загрузки
созданы отдельные копии его SQLite и uploads. В них запущены реальный API
старта, worker, цикл качества и API экспорта текущего Wizard. Weblate adapter
заменён детерминированными тестовыми ответами; реальные MT/quality endpoints
работающего Weblate на этом этапе не вызывались. Сеть тестового процесса
заблокирована socket guard. Аутентификация актора в копии подставлена только
для обращения к API старта/экспорта; настоящий SSO проверен выше на живом стенде.

Оба прогона завершились со статусом `completed`:

| Проверка | Обычный ответ | Ответ потерян после принятия |
| --- | --- | --- |
| Запросов тестового MT | 1 | 1 |
| Строк в запросе MT | Только пустая строка №2 | Только пустая строка №2 |
| Готовая строка исключена из первичного MT | Да | Да |
| После потери ответа использована прежняя квитанция | Не требуется | Да, без второй отправки |
| Оценка двумя тестовыми судьями | Обе строки | Обе строки |
| Применение проверенного исправления | 1 | 1 |
| Согласование повторов и повторная оценка | Только изменённый получатель | Только изменённый получатель |
| Финальная оценка/отчёт | completed, 0 остаточных тестовых проблем | completed, 0 остаточных тестовых проблем |
| JSON/XLSX/ZIP выдаются API | Да | Да |

Тестовое качество означает проверку поведения программы на заранее известных
ответах, не лингвистическую оценку настоящих моделей. Исправление готовой строки
здесь специально разрешено сценарием quality repair; её исключение из первичного
MT проверено отдельно.

Связанный pytest: 2 PASS, три предупреждения deprecated API зависимостей.
Внешних попыток соединений: 0. CRC полученных XLSX и ZIP проверен. Первый запуск
тестовой копии без uploads был корректно отклонён как `original_missing`; после
копирования исходных файлов оба прогона прошли. Исправления продукта не потребовались.

## Сохранность и протоколы

Все 21 предшествующая бизнес-запись Wizard совпали по хешам после проверки.
В ручном стенде созданы только отдельные синтетические проекты/черновики;
задания перевода создавались исключительно в копиях (в live jobs остаётся 0).
API и worker ручного стенда ready. Private test DB, сессии, файлы и ключи в Git
не публикуются.

Локальные протоколы основного рабочего каталога:
`.superpowers/local-testing-20261027/updated-full-workflow/` — `result.json`,
`ui-mock-chain.json`, `connected-tests.xml`, `connected-tests.log`, `network.json`,
`safety.json`, скриншоты и результаты normal/lost-response. Тестовые XLSX/ZIP
доступны там же. Эти результаты дополняют 555 связанных тестов Weblate,
65 проверок его producer API и 160 тестов Wizard, описанных в
`docs/operations/reports/2026-10-28-native-weblate-wizard-compatibility.md`.
