# source markup: замер правила закрывающего тега с атрибутом, 2026-09-15

Правило `source.tag_closing_has_attribute` из плана
`docs/product/plans/2026-09-11-loc-kit-source-validation.md`: закрывающий
Unity-тег (`</color>`, `</sprite>`, …) несёт `=` или пробельный атрибут,
например `</color=yellow>` из дефекта 525591. Проба:
`analysis/probes/source-markup-defects.py`, артефакт прогона:
`analysis/data/source-markup-defects-2026-09-15.json`.

## Проверка детектирующего пути

Живой прогон не содержит ни одного позитивного примера, поэтому
детектирующий путь пробы (пагинация, дедупликация, счётчик, примеры)
проверен отдельным smoke с замоканным API: две страницы юнитов, повторный
`(component, context)`, строка 525591, чистая строка и строка с двумя
независимыми битыми тегами. Проба следовала курсору на вторую страницу,
обработала 3 юнита вместо 4 (дедуп сработал), вернула 3 кандидата и три
примера. Данные инстанса при этом не менялись.

## Производственный замер не выполнен

Read-only прогон по `l10n.herocraft.com` требует отдельной авторизации
доступа и остаётся **ожидающим**. Единственный известный кандидат на проде —
`SpawnRate` Anvil Saga (дефект 525591) из полного LQA-экспорта
(`analysis/data/anvil-saga-fr-lqa-golden-2026-09-11.json`, 8 074 уникальных
source string на один случай; см. ревью плана). Ручная классификация
кандидатов как true/false positive будет дописана в этот документ после
производственного прогона; до него включать `GameSourceMarkupCheck` на прод
нельзя — это и есть гейт Task 2.
