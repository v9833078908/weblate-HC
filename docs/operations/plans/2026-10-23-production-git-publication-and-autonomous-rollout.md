# Фиксация прода в корпоративном Git и согласованный перенос Weblate и визарда

> Исполнение: `executing-plans`, последовательно в текущей сессии. Пользователь
> разрешил составить план и приступить к переносу через PL, затем выполнить
> бэкап, предусмотреть откат и установить последние изменения обоих приложений.

**Статус:** подготовка и локальная приёмка завершены. Merge/установка/перезапуск
отложены до нового явного разрешения пользователя.

**Уточнение пользователя после обследования:** отдельного сервиса PR нет,
администратора SCM не подключать; продолжать с существующим Git и правами,
изменения только в рабочих ветках. Подготовить анализ, тесты, проверку безопасности
и отчёт с файлами/результатами/планом переноса. Без нового разрешения не выполнять
merge в основную ветку, production-развёртывание или перезапуск служб. Старое
неопределённое задание визарда не возобновлять, учитывать свободное место.

**Цель:** сохранить проверяемые снимки фактического production-кода Weblate и
визарда в `http://10.39.40.3:8080/scm/git/ai_weblate` от `y.bazenkov`, перенести
подготовленные изменения через Pull Request и обновить оба сервиса без потери
переводов и повторения оплаченных запросов.

**Архитектура:** два независимых дерева кода в разных ветках одного репозитория.
Production-снимки отделены от веток обновления; PR каждого приложения направлен
в соответствующую базовую ветку. Не объединять несвязанные деревья механическим
merge. Установить Weblate до визарда с предварительно остановленным допуском
новых платных заданий. Существующую историю и настройки Git-сервера сохранить.

## Ограничения и проверяемые условия

- Секреты, `.env`, ключи, БД, пользовательские файлы, сырые ответы модели и
  закрытые резервные копии не публиковать в Git, включая историю импортируемых
  веток. Данные держать отдельно с закрытыми правами.
- Не считать локальную копию production-снимком без сверки с работающим кодом.
  Зафиксировать commit, dirty-файлы, digest, образ, mounts и способ запуска.
- Сохранить все существующие проекты и готовые переводы; исторические 1662
  перевода и 158 receipts сверить с актуальным production-baseline, если этот
  набор присутствует на целевом сервере. Локальный стенд не подменяет production.
- Не отправлять платные запросы ради приёмки. Не возобновлять автоматически
  неоднозначные старые задания. Уже принятый запрос не отменяется откатом кода.
- SCM-Manager 1.60: PR отсутствует; пользователь разрешил подготовку без него.
  Не обходить защиту основной ветки: никакого merge, production-развёртывания
  или перезапуска служб до нового явного разрешения. Публикуются только отдельные
  ветки. Проверка подготовленных изменений не является разрешением установки.
- Доступ к Weblate и визарду проверять раздельно. Не использовать пароль другого
  сервера без подтверждения его назначения.
- При откате сохранять актуальную БД и журнал оплаты. Не выполнять downgrade
  схемы и не возвращать старую БД поверх новых переводов.

## Вне объёма

Перенос БД или секретов в Git, смена учётных записей, изменение DNS/TLS,
несвязанные обновления Weblate, повторная оплата старых запросов и автоматическое
исправление существующих переводов ради тестирования.
