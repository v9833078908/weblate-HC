# Замер: соседние реплики в сегменте судьи (плечо H2 против прода)

Дата: 2026-09-04. Вопрос плана
`docs/llm-first/plans/2026-08-20-judge-dialog-context.md`: меняет ли поле
`context: {prev_source, next_source}` в сегменте (плюс один абзац промпта)
вердикты судьи на диалоге - и в какую сторону.

Драйвер: `analysis/probes/judge-dialog-context-probe.py`. Сырые ответы:
`analysis/data/judge-dialog-context-2026-09-04/` (`seat{1,2}-{H,H2}.json`,
`seat1-{H,H2}-rerun.json`, `run.log`, `rerun.log`).

## 1. Постановка

| Параметр | Значение |
|---|---|
| Корпус | `heart-abyss/hub-1`, fr, три подряд идущие сцены `hub1_first_1` (29), `hub1_ramen_1` (45), `hub1_teahouse_1` (35) = 109 юнитов из запечатанного дампа `analysis/data/hub1-remediation-2026-08-25/heart-abyss__hub-1__fr.json` |
| Соседи | `position ± 1` по **полному** дампу (396 юнитов), как дал бы `Unit.position` в проде; 108 юнитов с `prev_source`, 109 с `next_source` |
| Плечо H | продовый `verdict.txt` и `judge._segment` на HEAD, без изменений |
| Плечо H2 | H + `context` в каждом сегменте, у которого есть сосед + абзац `CONTEXT_RULE` перед абзацем про `glossary` (текст - в драйвере и в сырых json) |
| Сиденья | продовые (`dev-docker/docker-compose.yml`): seat 1 `deepseek-v4-pro`, batch 2, reasoning on; seat 2 `atlas/qwen3.8-max`, batch 1, `extra_body.enable_thinking=false`; temperature 0; ключ - ключ dev-контейнера |
| Состав батчей | одинаковый в обоих плечах: внутри пары различаются только `context` и абзац |
| Повторы | seat 2: 2 × 109 на плечо; seat 1: 1 × 109 на плечо, затем 3 × 16 на потерянных батчах и юнитах-мотиваторах (`rerun`) |
| Gold | нет. Расхождения между плечами разобраны вручную (RU и FR читаются ревьюером); повторы того же плеча - шумовой пол |

Прочее: транспорт прокси терял батчи по известному ~30 с сбросу
(`2026-08-26-litellm-transport-reset-rate.md`): seat 2 - 3 батча на плечо
из 218, seat 1 - 4 (H) и 6 (H2) из 55; повтор `rerun` закрыл нужные.

Побочная находка, не предмет замера: промпт прода получает коды языков
(`build_request` подставляет `source_language.code`), поэтому системный
промпт читается «a ru to fr video game localization… translated back into
ru». Драйвер воспроизвёл это как есть.

## 4. Вывод

1. На seat 2 - единственном детекторе для ~41 % флагов в проде
   (`2026-09-03-judge-thinking-passthrough.md`) - окно ±1 не меняет ни
   одного вердикта на 109 диалоговых юнитах; +9 % входных токенов на
   каждом юните каждого компонента.
2. На seat 1 окно ±1 закрыло 1 из 3 известных ложных срабатываний
   «изолированный сегмент» (`first_1_4`), не закрыло два других
   (`teahouse_1_11`, `first_1_3`) при дословно поданном соседе и ничего не
   добавило к обнаружению; +10 % входа, +15 % выхода, +13 % времени.
3. Реплика-мотиватор `ramen_1_13` окном ±1 недостижима по построению.

Гейты плана G2/G3 (польза) не пройдены ни на одном сиденье; G4/G5
(не хуже) формально пройдены, потому что эффекта нет вообще. Гипотеза
«минимум дискурс-контекста снимает ложные срабатывания на обрывках»
измерена и отклонена: модель, получив соседа, не связывает разорванное
предложение (`раньше… / Чем ты дойдёшь`) и не пересматривает ответную
реплику. Решение - в ревью
`docs/llm-first/reviews/2026-09-04-judge-dialog-context-review.md`.
