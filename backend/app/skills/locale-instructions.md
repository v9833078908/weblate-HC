# Locale instruction authoring (HCGameLoc, GPL-3.0-or-later)
Write one compact Russian language_instructions entry for every exact target code.
Never merge scripts or regions. zh_Hant means traditional script, not a chosen Taiwan
or Hong Kong market. If region is unknown, say it requires confirmation. pt_BR and
es_MX have explicit markets; pt/es do not inherit those markets. Respect confirmed
BDHC locale_rules and voices above generic locale_guides. Do not arbitrarily force
formal address on character dialogue. Omit absent character details. For an unfamiliar
locale, preserve the exact code and acknowledge no verified local guide is available.
Each entry must fit 1000 characters. Do not add/remove any target code.
